# 粮堆发热三维等值面系统

浏览器内运行的粮情三维可视化系统：TypeScript + WebGL2 + Web Worker + IndexedDB，零运行时第三方依赖。

## 运行

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 类型检查 + 生产构建
npm test         # 等值面算法独立验收（水密性 / 体积精度 / 耗时）
npx tsx scripts/e2e_smoke.ts   # 真实仓房几何端到端管线冒烟
```

首次打开自动生成两个示范仓（平房仓带扒低粮面、浅圆仓带锥形堆尖），各含全年每 3 天一次的巡测数据，内置中下层发热、南墙晒热、粮面结露三类异常及坏点/断线。

## 六个页面

- **仓房档案**：分仓型建档，粮面高程由实测控制点 IDW 拟合（平房仓扒低、浅圆仓锥尖）
- **电缆布置**：平房仓行列网格、浅圆仓同心圈，点数随粮面高程变化；坏点/断线标记
- **巡测数据**：按日期列表、温度统计、CSV 导入导出；坏点读数为 NaN，插值跳过绝不作 0℃
- **三维粮情**：时间轴拖动/播放、多层半透明等值面（仓温 +3/+5/+8℃）、电缆测点、双击测点历史曲线、任意剖面等温线、巡仓报告导出
- **隐患处置**：发热团登记，机械通风/环流熏蒸/倒仓措施前后体积与温度对比
- **设置**：网格分辨率（可调到 200/边）、阈值、帧率、主题、数据管理

## 核心架构

```
src/core
  mc_tables.ts      MC 角点/边/面定义，Nielson 渐近线鞍点判定
  tri_table.ts      离线生成 256 case 三角连接表（面配对→边图→走环→扇形）
  marching_cubes.ts 运行时查表抽取，边交点全局缓存，分块并集裁剪，发热团连通标记
  grid.ts           测点空间哈希 IDW 插值、粮堆掩码、封闭化 sealFieldForIsosurface
  boundary 封口     粮堆外/domain 边界赋冷值，热区被冷值包围，等值面自然收口
  geometry.ts       仓房几何、粮面拟合、电缆布置
  mock_data.ts      全年巡测合成（三类异常 + 坏点断线）
  compute_worker.ts 插值/抽取/时间插值全部在 Worker，不阻塞主线程
  blob_tracker.ts   发热团跨日期空间重叠跟踪
src/webgl           WebGL2 渲染器、轨道控制、场景几何
src/app, src/pages  状态、路由、六个页面、报告
```

## 水密性设计要点

1. 角点编号严格按 `CORNER_OFFSETS`，与内存线性布局区分
2. 分块裁剪遍历格覆盖的最多 8 个 chunk 取极值并集，避免跨块格误跳
3. 相邻格共享同一物理格边的交点顶点，二义面由渐近线判定保证两侧拓扑一致
4. 贴粮面/仓壁的等值面通过冷值封闭化收口，无开口

验收用合成已知半径球体：三档分辨率欧拉示性数均为 2、零破洞，MC 网格体积与数格体积差 < 0.8%（红线 2%），200³ 抽取约 0.5 秒（红线 1 秒）。
